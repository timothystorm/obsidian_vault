Panty Chef is the beginning of an AI journey.  

## ✅ Phase 1
1. Basic wrapper around an AI agent that can take in an inventory of pantry items
2. This inventory is sent along, with an optional prompt, to an AI agent to find or produce 0-6 recipes with the ingredients
## ⭕️ Phase 2
1. Create a utility TUI that can be used to store and convert recipes into JSON models
2. These models will eventually be input into a vector database for RAG
## Phase 3
1. Embed the recipes into the vector database using an open model
## Phase 4
1. Embed the user's prompt and inventory to lookup the user's own recipes
2. Add these user recipes into the agent prompt and inventory to do a lookup of recipes both personal and general
